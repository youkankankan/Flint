# Flint v0.1.1

MinecraftサーバーをWindows上で作成・起動・監視・管理するデスクトップアプリ、Flintの累積アップデートです。
旧Overseerから進めてきた機能追加、UIの再設計、操作性の改善、不具合修正と、v0.1.1の自動更新強化をまとめています。
この一覧は開発期間全体の変更履歴であり、すべてがv0.1.0からv0.1.1への差分という意味ではありません。

## 主な変更

- ターミナル中心のOverseerから、Tauri + ReactのWindowsデスクトップアプリへ移行。
- アプリ名・配布物・設定・Bridgeの名称をFlintへ統一。
- ダークパープルと淡いラベンダーを基調にしたGlass UIへ再設計。
- GUIから新規サーバーを作成するウィザードと、Forge・NeoForge・Mohistを含むブランド別導入を追加。
- サーバー全体を扱うExplorer風ファイル画面、Mod解析、Minecraft風インベントリ編集を追加。
- Dynmap連携を専用のマップ画面へ分離。
- クラッシュ・起動失敗・性能低下の調査を助けるAI Packを強化。
- 起動、監視、RCON、設定保存、バックアップ、長時間ログ保持の安全性と安定性を改善。
- 署名付き自動更新の確認・通知・適用・再試行を整備。

## デスクトップアプリ・ブランド

- Tauri + React + TypeScriptのGUIを本体とし、既存Ink TUIは互換・開発用の旧実装として維持。
- Windows用exe、NSISインストーラー、MSIと、更新用の署名・manifestを生成可能に。
- OS用アイコンに「Strike / Luminous」を採用。小サイズ用調整を含むマルチサイズICO、SVG、PNGを用意。
- アプリ・ウィンドウ・インストーラーのアイコンを統一。サイドバーはFlintのテキストロゴと「Made by youkan_」を維持。
- アプリのバージョンをサイドバーに表示。
- 旧Overseer設定の一方向インポートを追加。既存のFlint設定を優先し、Java、サーバー、バックアップ先などの指定を保持。
- 稼働中の旧データ領域は勝手に移動せず、停止後の移行へ延期。競合する旧・新フォルダーを無断で統合しない。

## UI・操作性

- 色、余白、文字サイズ、角丸、境界線、状態色、アイコン、操作フィードバックを共通化。
- ページ遷移、サイドバー選択、Settings切替、数値、バー、通知、メニューのアニメーションを整理。
- 大量の行が戻るたびに演出を繰り返す挙動や、長すぎる段階表示を抑制。
- OSの「視覚効果を減らす」設定に対応し、数字・バー・pulse・ボタン演出も抑制。
- 初回ロードのブランド表示を整理し、余分な線や装飾を削減。
- 最大化時の広すぎる余白、ヘッダーと本文の位置、狭い幅での文字や操作のはみ出しを調整。
- 不要な横スクロールバー、サイドバーの目立つスクロール表示、選択インジケーターの位置ズレを改善。
- タイトルバーのドラッグ、ボタン・アイコンの中心位置、ウィンドウ移動時の負荷につながる表示処理を見直し。
- 非表示・非アクティブ時の監視頻度を下げ、復帰時に再同期。非表示時の地図表示も休止。
- 日本語を標準に、主要UIの日本語・英語切替と保存に対応。
- Ctrl+KのCommand Paletteを整理し、画面外へのはみ出しと不要な項目を削減。
- 通常ボタンのTab移動による不要な強調や、非編集領域のブラウザ標準右クリックメニューを抑制。入力欄・確認ダイアログのキーボード操作は維持。
- 重複する通知の抑制と表示件数制限を追加。

## Dashboard・画面構成

- サーバー概要、状態、稼働時間、Bridge、RCON設定、TPS、メモリ、CPU、プレイヤー数を整理して表示。
- 起動・停止・再起動・保存・バックアップなどの主要操作をヘッダーに集約。
- アクティビティに起動、停止、コマンド、バックアップ、プレイヤー入退室、エラーなどを表示。
- クラッシュ情報からAI Packやエクスプローラーのレポート保存場所を開ける導線を追加。
- Dashboardの最近のログを削除し、ログはConsoleへ、地図はMapへ集約。
- Health / Crash Centerの独立画面を削除。内部の安全確認・診断データは起動検証とAI Packで維持。
- データ未取得・空状態・helperエラーを明示し、実データがない項目に架空の値を表示しない。

## 新規サーバー作成・初期設定

- Serversから段階式の新規作成ウィザードを開けるように変更。
- ブランド、Minecraftバージョン、ビルド、名前、保存先、Java、Xms/Xmx、ポート、最大人数、ゲームモード、難易度、ワールド名などを設定可能に。
- 初心者向けの推奨値と詳細設定を分離。戻る・開き直す操作でも入力を保持。
- Vanilla、Paper、Purpur、Fabric、Forge、NeoForge、Mohistの作成アダプターを実装。
- 各配布元のメタデータから実在するバージョン・ビルドを取得し、作成開始時に再検証。取得失敗時に別ブランドや架空のビルドへ逃げない。
- Forge / NeoForgeは公式インストーラーを実行し、生成されたWindows用引数ファイルを起動対象として使用。インストーラーJarをサーバー本体として起動しない。
- Mohistは公式アーカイブと配布メタデータ・チェックサムが対応するビルドを使用。既存サーバーの自動更新・ダウングレードは行わない。
- Javaの検出・明示選択、要求バージョンとの照合、見つからない場合の導入案内を追加。
- EULAへの明示同意、設定生成、ダウンロード・インストール進捗、キャンセル、失敗理由を表示。
- ストリーミング転送、期限、再試行、配布元が提供するハッシュ・サイズの検証に対応。
- 専用stagingで準備し、失敗・キャンセルした不完全なサーバーを正式登録しない。
- 完了後の明示操作で作成したサーバーのDashboardへ移動。他の稼働中サーバーを停止・選択変更しない。
- 既存サーバー用SetupではJar、Java、EULA、properties、RCON、Bridge、バックアップ先を確認。
- Setupの事前検証と失敗時の復元を追加し、途中まで書かれた設定やEULAだけが残る問題を修正。

## 起動・停止・監視・RCON

- HTTP Bridgeによる監視、コマンド専用RCON、独立PowerShellランチャーの役割分離を維持。
- GUIから直接通信・ファイル操作せず、ServerSession / CommandRouter / ServerContextを経由する構成へ整理。
- アプリを閉じてもMinecraftが独立稼働するdetached起動を使用。
- 起動ごとにセッションID・開始時刻を作成し、標準出力、標準エラー、終了コード、ランチャーエラー、起動完了、候補レポートを関連付け。
- Java起動、Mod読込、ワールド読込、稼働中終了を調べやすい記録を追加。
- 再起動指示と通常停止を区別し、起動完了前の失敗を無限に自動再起動しないよう改善。
- 古い状態ファイルのPIDが別プロセスへ再利用された場合の誤認を修正。対象パスとプロセス開始時刻を照合。
- Javaが生きているだけでOnlineにせず、Bridgeや今回の起動完了記録を根拠に判定。
- 停止ジョブ中のStopping表示を維持。通常停止のタイムアウトで勝手に強制終了せず、明示操作だけで強制停止。
- 起動・バックアップ・ファイル変更に共有ロックと起動intentを追加。コピー確定前にも状態を再確認。
- 状態JSONの一時ファイル経由の置換と、起動失敗時のロック・intent後片付けを改善。
- Bridge HTTPに絶対期限とキャンセルを追加。少量ずつ届く応答でも無期限に延長しない。
- サーバー・設定・選択プレイヤー変更時の旧監視を中断し、古い結果を新しい画面へ反映しない。
- snapshotや素材取得の待機が停止・コマンドを塞がないよう、helper RPCを要求IDで振り分け、監視結果をキャッシュ。
- helperエラー時にデモへ切り替えず、エラーを表示。通信期限超過でhelperを無条件にkillしない。
- RCON接続を連続コマンドで再利用し、操作ごとの接続・切断を削減。監視・keepalive目的のコマンドは送らない。
- RCON応答末尾の欠落、空応答、複数要求の結合による切断を扱う処理を改善。
- タイムアウトしたコマンドは自動再送せず、二重実行を防止。
- BridgeのHTTP切断時に余分なスタックトレースや二重応答を出す処理を修正。

## Console

- 画面全体を使うターミナル形式へ変更。1行ごとのカード表示を廃止。
- monospaceの時刻・level・本文を整理し、時間表示のズレ、行間、色分けを改善。
- 検索、選択行コピー、コマンド入力、履歴、Minecraftコマンド・プレイヤー名の補完に対応。
- IME変換中のEnterと送信を区別し、Tabを補完に使用。
- filter / Pause / Wrap / Regex / 常設Autoscroll切替など、不要になった操作UIを削除。
- 一番下にいる場合だけ新着へ追従。過去ログを見ているときは位置を保ち、必要時だけ「最新へ移動」を表示。
- HTTP / HTTPSのリンクだけを安全な外部リンクとして扱い、危険なURL方式を開かない。
- コマンドと応答・失敗理由をコピー可能なログへ表示。「応答本文はありません」という不要な行を削除。
- Minecraftの再起動、ログ回転、一時的なlatest.logの消失で収集済み履歴を消さない。
- 全履歴のRAM配列を一時ディスクspoolへ変更。GUIは直近5000件を保持し、以前の記録は履歴ページから参照。
- 長い行でも過去ページに抜けが生じないよう修正。UTF-8の分割、重複行、ログIDとカーソルを扱う処理を改善。
- 未選択サーバーのログを永久に監視し続けないよう修正。

## ファイル・Mod管理

- 従来のModsタブを、サーバーフォルダー全体を扱う「ファイル」と「Mod解析」へ再構成。
- Explorer風のコンパクトな一覧、並べ替え、検索、列幅調整、詳細ペイン、パンくず、戻る・進む・上の階層に対応。
- Ctrl / Shift選択、ドラッグ矩形選択、Ctrl+A、矢印・Home / End、右クリックメニュー、名前変更、新規フォルダー、切取・コピー・貼付を追加。
- 文字選択が矩形選択を妨げる問題を修正。行間と周囲の余白を増やし、範囲選択しやすい配置へ調整。
- Windowsからのファイル・フォルダーのドロップと選択ダイアログによる取り込みを追加。
- 小さいUTF-8テキストを内蔵エディターで編集でき、設定ファイルには構文・revision確認と変更前コピーを適用。
- 一般ファイルの削除はFlint内の隔離領域へ移動。Mod解析からの完全削除は確認を要求。
- Modの有効・無効切替と有効/無効フォルダー間の移動を追加。無効Modはloaderの読込先から分離。
- Forge / NeoForgeのTOML、Fabric / QuiltのJSON、複数Mod ID、同梱Jarや別名IDを考慮した依存解析へ改善。
- 必須・任意・client依存を区別し、欠落、無効、バージョン不一致、未確認を分けて表示。
- Minecraft / loader / Javaの依存rangeを、確認できる構成情報と照合。分からないものを充足扱いしない。
- client向けという推測と、メタデータでclient-onlyと確認できたものを区別して誤検知を削減。
- 破損Jar、同一Modの重複、危険なパス、リンク、上書き衝突、上限超過を拒否。
- ファイル・Modの変更は停止確認と共有ロックを必須にし、稼働中・起動中・不明時は拒否。
- コピー中の元データ変更、起動競合、途中失敗を検出し、一時コピーの破棄や復元を実施。

## プレイヤー・インベントリ

- 検索可能な一覧と「概要 / インベントリ / 詳細」を分離し、情報を分類して表示。
- Bridgeが提供するUUID、接続情報、IP、ping、ワールド、座標、体力、食料、経験値、ゲームモード、権限、接続日時などを表示。
- オフラインでも最後の観測結果やplayerdataを表示し、保存データであることと取得時刻を明示。
- 常時は軽量なプレイヤー一覧、選択中のプレイヤーだけ詳細取得とし、全員分のインベントリを毎回取得する処理を削減。
- Minecraft風のスロット表示と、ローカルのクライアントJar・Mod Jar・明示リソースパックによる元テクスチャ表示を追加。
- 標準的なアイテム・ブロックモデル、CustomModelData、一部の色を扱うプレビューを追加。
- ドラッグ表示の位置ズレ、画像やアイコンの中心ズレを修正。素材欠落時の「?」は中立的な代替表示へ変更。
- スタック単位のドラッグ移動・交換、右クリック削除、空きスロットへのID・個数指定追加を実装。
- 編集有効化スイッチと二重確認を削除し、選んだ操作を直接反映。revision確認と変更前バックアップは維持。
- オフライン編集では完全なNBTを扱い、無関係なタグを保持。稼働中は対応Bridgeがサーバースレッドで確定し、停止中だけCoreが直接置換。
- ログイン競合、外部変更、古いrevision、編集中コンテナーなどを検証し、失敗時に危険な書込へフォールバックしない。
- 全員のインベントリを10分周期でテキスト記録し、読み取り専用の過去履歴を表示。
- 履歴の保存件数・期間・容量を設定可能に。古い履歴の自動整理は明示同意がある場合のみ実行。
- ダメージを与えない雷、ハート、祝福パーティクルの演出を追加。対象はオンラインプレイヤーに限定。

## マップ・接続アシスタント

- ローカルDynmapを検出し、専用Map画面へ埋め込み。ワールド・表示方式・プレイヤー追従を選択可能に。
- 「地図を操作」ボタンを廃止し、開いた時点から操作可能に。
- 未導入、無効、設定不正、認証必要、応答期限超過などを区別して表示。
- Serversにゲームポート、待受アドレス、ローカルTCP応答、登録サーバー間の競合、空き候補を確認する接続アシスタントを追加。
- 同時起動用の別ポート候補と、接続先の「IP:ポート」を表示。明示したポートは勝手に変更しない。
- 明示同意に基づくWindows UPnPの転送設定・解除を追加。ゲーム用TCPだけを対象にし、RCON / Bridgeは公開しない。
- 既存の他アプリの転送設定を上書き・削除しない確認を追加。
- 空きポート候補の取得失敗を、実施済みの転送設定変更の失敗と混同しないよう修正。
- ローカル応答や転送設定があるだけで「インターネットから接続可能」と断定しない。

## バックアップ・設定保存

- バックアップの履歴、作成時刻、対象ワールド、記録済みサイズ、検証状態を表示。保存先を開く、確認付き削除、復元前dry-runを追加。
- 一貫性を保証できないオンラインコピーを廃止し、停止確認済みのバックアップだけを許可。
- 全対象のコピー成功後に公開し、その後だけ既知の古い世代を整理。失敗したコピーを成功扱いしない。
- バックアップ名の衝突、欠落ワールド、危険な保存先、リンク、未知の世代の誤削除を防止。
- `level-name`を共通解決し、固定world名に依存していたplayerdata・stats等の読取先を修正。
- アプリ設定とサーバー別設定を分離し、編集開始時のrevisionと操作先scopeを照合。
- Settingsを分類し、保存・破棄・再起動後反映を明示。JVM引数、server.propertiesや対応設定ファイルを編集可能に。
- 入力中のパスがsnapshot更新・タブ切替で既定値へ戻る問題を修正。
- 不正JSON・型・破損設定を無断で既定値に戻さず、原本を保持してエラーを表示。
- 複数ファイルの設定保存に失敗した場合の復元を追加。

## AI Pack・診断

- 問題説明と収集選択を左、プレビューを右に置く専用画面へ集約。
- Markdownに加え、要約、AI向けプロンプト、manifest、ログ、設定、Mod依存、履歴、診断を整理したZIP出力に対応。
- 取得元・方法・時刻・起動セッションと、成功・失敗・未対応・省略・切り詰めを明示。
- 過去のlatest.logやクラッシュレポートを今回の起動失敗の原因として誤認しない出典表示を追加。
- 起動前後のstdout / stderr、終了コード、ランチャーエラー、重要エラー周辺とスタックトレースを収集。
- TPS / MSPT、CPU / メモリ、JVM heap / GCなどの軽量な時系列と、設定・Jar構成の変化を記録。
- 重い診断は別途同意制とし、BridgeのJVM / スレッド情報、一部のワールド・チャンク・entity情報を取得。
- Bridge応答不能時に備え、PID同一性を再確認してからJDKのjcmdでスレッド・heap情報・起動引数を取得する経路を追加。
- 定義の異なるチャンク数を数値の不一致だけで異常扱いせず、事実・仮説・不足情報を分けるAI向け調査指示を生成。
- パスワード、トークン、IP、ユーザーパス等をマスクし、共有前に出力を確認可能に。外部AIへ自動送信しない。

## 自動更新・安全性・配布

- 起動4秒後、表示中の1時間ごと、一定時間経過後のアプリ・ネットワーク復帰時に更新を自動確認。
- バックグラウンドの確認失敗で通知を乱発せず、更新があればバージョン・変更内容と「更新する / 後で」を表示。
- ユーザーの確認後に期限付きでダウンロードし、署名を検証して適用。
- 適用前にhelperの正常終了を確認。バックアップ、作成、コマンド、インベントリ収集、ネットワーク処理中は適用を拒否。
- 更新中のCore監視を休止し、更新失敗時は接続を再開。Minecraftサーバーのプロセスツリーをkillしない。
- 安全確認・適用・再起動の状態を分け、失敗後の再試行と、再起動だけ失敗した場合の二重インストール防止を追加。
- 適用後の再起動に失敗してもウィンドウを閉じ直せるよう、終了済みCoreへの再終了要求を修正。
- updaterのネイティブresource解放と、重複チェック・重複適用の防止を追加。
- 開発HTTP APIにloopback Host、許可Origin、token、JSON Content-Typeの検証とproduction無効化を追加。
- `release:draft`でバージョン・manifest・署名ファイルの対応を確認してGitHub Release下書きを準備可能に。自動公開・既存Releaseの上書き・ソースのpushは行わない。

## 利用前の注意・既知の制限

- 詳細監視・オンラインインベントリ操作・演出には、対応するFlintBridgeが別途必要です。FlintBridgeの現行ソースは0.6.0です。交換はサーバーを正常停止してから行ってください。
- Forge / NeoForge / FabricへBukkit用FlintBridgeをそのまま導入することはできません。取れない情報はUnavailableとなります。
- Spigot / Bukkitの自動作成、Javaの自動インストール、Bridgeの自動導入は未対応です。Forgeの古い版、NeoForgeのlegacy / beta、Mohistの全ビルドを網羅するものではありません。
- 地図には別途Dynmapが必要です。ログイン必須Dynmapの埋め込み、自動導入や地形の独自描画は未対応です。
- UPnPはルーター・回線に依存します。外部到達保証、自動ファイアウォール変更、CGNAT回避、トンネル、IPv6転送は含みません。
- インベントリは既存スタック全体の移動・交換で、分割・結合やMod独自の追加コンテナー編集には対応しません。一部の専用renderer・動的モデルは完全には再現できません。
- 復元dry-runは事前検証・計画作成です。ワールドを自動で復元する機能ではありません。
- Console検索は読み込んだ表示範囲が対象です。helper異常終了後のspool自動復旧と、全履歴横断検索は未対応です。ログ・診断記録のディスク使用量に注意してください。
- Forge / Mohist内部の全チャンクチケット、未完了future、全Mod処理の完全な追跡は未対応です。未取得情報を作ったり、AIが必ず原因特定できると保証するものではありません。
- 自動更新はGitHub Releaseの公開とLatest指定後に配信されます。更新機能のない旧版は一度インストーラーで更新してください。旧Overseerからの異なるアプリID・署名をまたぐ更新は保証しません。
- 旧版とFlintを同じサーバーに対して同時に操作しないでください。編集・更新前には通常のワールドバックアップも確保してください。

## 検証範囲

- typecheck、単体・回帰テスト、隔離したhelper RPC、Rustテスト、ブラウザのGUIテスト、GUI / Core / helper / Windows配布ビルドを実施。
- 自動更新はmockによる同意・キャンセル・通信失敗・処理中拒否・再試行・再起動失敗と、通知UIの幅別表示を検証。
- 対象の公式loader導入は使い捨てディレクトリーでの過去検証記録がありますが、全ブランド・全構成でMinecraftを起動して遊べることの保証ではありません。
- 今回の安定化・更新テストでは、本番サーバーの起動・停止、ワールド・Mod・playerdataの変更、実ルーターの設定変更は行っていません。
- 実Mohistでの一連の起動・保存・再起動、長時間稼働、配布済み旧版からの実インストーラー更新は引き続き実環境での検証が必要です。
- 大きいGUI chunkのビルド警告は残ります。すべての不具合がなくなったことを保証するリリースではありません。
