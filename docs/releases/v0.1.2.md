# Flint v0.1.2

接続設定を分かりやすくし、新規サーバー作成から友達を招待するまでの流れを改善しました。外観の選択肢と、画面・操作の細かな動きも整えています。

## 接続アシスタント

- サイドバーの「管理」に独立した「接続アシスタント」タブを追加。
- よく使うポート開放・解除を、折りたたみのない最上段の操作へ移動。
- 「Windowsもまとめて設定」で、Windowsファイアウォールの受信許可とルーター転送を一括設定。設定変更には明示同意、Windowsの変更には承認が必要です。
- 接続中のネットワーク種別を調べ、そのネットワークに対応する受信許可を作成。
- 接続先を「自分のPC」「同じWi-Fi・LAN」「離れた場所の友達」に整理し、コピー・共有を改善。
- ポート競合、転送先の不一致、自動開放に対応しないルーターなどの理由と、次に必要な操作を表示。
- 診断の詳細や手動設定の説明を折りたたみに集約。
- 設定済みの転送や受信許可と、インターネットから実際に参加できたことを区別。
- RCON・Bridgeの管理ポートを公開せず、他アプリの転送設定は上書き・削除しません。

## 新規サーバー作成

- 作成ウィザードの最後に「接続設定」を追加。作成、接続設定、プレイ準備へ連続して進めます。
- 作成したサーバーとそのゲームポートを確認してからネットワーク操作を表示。
- 「あとで設定」で接続設定をスキップ可能。
- 同意なしの設定変更を防ぎ、ネットワーク処理中のウィザード終了を抑制。
- Forge・NeoForge・Fabric・Vanilla向けの専用Bridge、Bukkit系Bridgeの自動更新予約、対応するBukkit系サーバーへのDynmap自動導入を追加。
- Spigot / CraftBukkitでは公式BuildToolsを使用。対応版やBridgeの機能はブランドごとに異なります。

## 外観・アニメーション

- Flint Glass / Liquid / Graphiteの外観と、Lavender / Ice Blue / Ocean / Mint / Rose / Champagne / Silver / Monoの配色を選択可能。
- 外観のプレビュー、保存、取り消しを整備。編集中のパスやサーバー設定を保持。
- タブ変更時も、上部のタイトル、サーバー状態、更新ボタンの位置が安定するよう調整。
- ページの二重表示や文字の残像、繰り返される入場演出を抑制。
- サイドバーの選択表示、設定タブ、検索パレット、ダイアログの速度と動きを統一。
- アイコン操作の不自然な縮みを減らし、保存中は同じアイコン位置で進捗を表示。
- 狭いウィンドウの操作配置と、OSの軽減モーション設定への対応を改善。

## 更新方法

既存のFlintではアプリ内の更新確認から適用できます。更新が見つからない場合は `Flint_0.1.2_x64-setup.exe` を実行してください。
Minecraft用Javaは別途必要です。アプリの更新は、Minecraftサーバーを停止する操作ではありません。

## 検証と制限

- 型チェック、回帰テスト、接続画面・作成ウィザード・画面遷移のブラウザUIテスト、GUI / Core / helper / Tauriビルドを実施。
- ネットワークのUI・安全性テストは模擬環境で実施。今回のテストで実ルーターやWindowsの受信許可は変更していません。
- UPnPの対応状況、共有回線（CGNAT）、二重ルーターなどにより、自動設定だけでは外部公開できない場合があります。転送設定の成功は外部接続の保証ではありません。
- Javaの自動インストール、CGNAT回避用トンネル、IPv6ポート転送は含みません。
- Native Bridgeは基本監視向けです。Bukkit版と同等のインベントリ操作・内部診断を全ブランドで提供するものではありません。
- 全Minecraft版、Mod構成、回線環境を網羅した動作保証ではありません。設定やModの変更前にはバックアップを確保してください。

以前の累積変更は [v0.1.1](v0.1.1.md) を参照してください。
